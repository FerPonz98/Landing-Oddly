# Oddly

Landing de **Oddly**, consultora de marketing en Bolivia. Evaluamos cada empresa y recomendamos la estrategia que mejor responde a sus objetivos de ventas.

🌐 **https://oddly.com.bo**

## Tecnologías

Next.js · React · TypeScript

## Desarrollo local

Requiere Node.js 20.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abrir http://localhost:3000

## Idiomas

Español, inglés y portugués.
